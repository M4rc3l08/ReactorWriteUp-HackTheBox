Reactor es una máquina Linux fácil centrada en ReactorWatch, un panel de monitorización nuclear basado en Next.js 15.0.3 / React 19.0.0 expuesto en el puerto 3000. La aplicación es vulnerable a CVE-2025-55182 (React2Shell), una deserialización insegura en React Server Components que permite RCE sin autenticación. Con un PoC público obtenemos acceso como la cuenta de servicio node. Desde ahí recuperamos una base de datos SQLite, crackeamos un hash MD5 y accedemos por SSH como el usuario engineer. La escalada abusa de un servicio root iniciado con el flag --inspect de Node.js: tunelizamos ese puerto de depuración, nos conectamos vía protocolo V8 y ejecutamos código directamente como root.
